# BlueJoule Specification

This branch holds the **latest stable version** of the BlueJoule specification.

No version has been released yet. The working draft for the next release is on
[`RC-26.09`](https://github.com/em-foundation/bluejoule-spec/tree/RC-26.09), and the pull request
from that branch is where it is being discussed.

## Branches

`main` holds the latest stable version. An `RC-<release>` branch holds the working draft for an
upcoming release, and the pull request from that branch to `main` is the discussion area for it.
